# CONTRIBUTING.md

Use this skill when documenting how people should contribute to a project.

## What It Is For

`CONTRIBUTING.md` explains the collaboration process: branches, commits, pull requests, reviews, tests, and issue reporting.

## How To Use It

- Describe the expected workflow from issue to pull request.
- List commands contributors should run before submitting.
- Explain review expectations.
- Link to coding standards and testing docs.

## Example Content

```markdown
# Contributing

## Workflow

1. Create a branch from `main`.
2. Make a focused change.
3. Run tests and formatting.
4. Open a pull request with a clear summary.

## Before Opening A PR

- Run `npm test`.
- Update docs if behavior changed.
- Add screenshots for UI changes.
```

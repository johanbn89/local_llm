# DEVELOPMENT.md

Use this skill when documenting how developers work on the project locally.

## What It Is For

`DEVELOPMENT.md` describes setup, local execution, useful commands, dependencies, and common development workflows.

## How To Use It

- List required tools and versions.
- Include setup commands.
- Explain how to run the app locally.
- Include common troubleshooting notes for local development.

## Example Content

````markdown
# Development

## Requirements

- Node.js 20+
- Git

## Setup

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

## Useful Commands

- `npm test`: run tests
- `npm run lint`: run lint checks
````

# README.md

Use this skill when working with the main entry document for a repository.

## What It Is For

`README.md` is the first document most humans see. It should explain what the project is, why it exists, how to run it, and where to find deeper documentation.

## How To Use It

- Keep it human-facing and practical.
- Link to deeper docs instead of duplicating everything.
- Include setup and quick-start commands.
- Mention important agent or skill locations if the repo uses them.

## Example Content

````markdown
# Project Name

Short description of what this project does.

## Quick Start

```bash
npm install
npm run dev
```

## Documentation

- Architecture: `ARCHITECTURE.md`
- Development: `DEVELOPMENT.md`
- Testing: `TESTING.md`
- Deployment: `DEPLOYMENT.md`
````
